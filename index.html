开源语音合成引擎的统一平台

八个语音合成引擎，同一个平台

Mizuoto 把 CosyVoice、F5-TTS、GPT-SoVITS、OmniVoice、Qwen3-TTS、VoxCPM、Fish Speech 和 IndexTTS 收进一个网页界面、一套命令行和一个 HTTP 接口：合成语音、克隆与设计音色、转换与编辑语音、朗读长篇作品，并用你自己的录音微调模型。

WORKFLOW

从安装到第一段语音

四步走完整个流程，每一步在网页界面和命令行中都有对应做法。

  1. 01

    安装 Mizuoto

    先装好适合本机硬件的 torch，再从 PyPI 安装 Mizuoto（也可用 Docker 镜像或源代码），然后运行 mizuoto webui。

  2. 02

    下载模型

    引擎都已内置，无需单独安装；选一个模型，Mizuoto 会下载并校验它。演示引擎不需要下载，可以先用它熟悉界面。

  3. 03

    合成

    选择模型和音色，输入文本，边生成边听；结果连同参数一起保存在历史中。

  4. 04

    做成自己的

    把参考音频存进音色库，用项目朗读长篇作品，或用自己的录音微调模型。

WHY MIZUOTO

引擎各不相同，用法始终一致

每个引擎都原生移植并忠实复现上游的输出，下载、显存、排队与格式的差异交给 Mizuoto 处理。

  • 一种请求，八个引擎

    无论由哪个引擎处理，请求、音色、参数、任务与结果的形式都相同；不支持的选项在任务开始前就会指出。

  • 所有引擎原生运行，只需一个环境

    每个引擎都移植到 Mizuoto 基于 torch 的运行时上，在服务器进程内运行：只有一个 Python 环境，不必为引擎单独搭建；在 CPU 上与上游的输出逐样本一致。显存不够时，权重从内存流式加载，而不是加载失败。

  • 网页、命令行与接口同源

    三者调用同一套核心操作，命令行的 --json 输出与 API 相同；另有兼容 OpenAI 的 /v1/audio/speech。

  • 边生成边播放

    通过 WebSocket 或分块 HTTP 流式传输音频，CosyVoice 还能边接收文本边合成；完整结果同样保存下来。

  • 引擎可以放在另一台机器

    在有显卡的机器上运行 mizuoto agent，本机的 Mizuoto 就能把那里的引擎当作自己的来用。
