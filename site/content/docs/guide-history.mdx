**历史** 页列出所有结果，最新的在最前：合成页、音色页的试听、设计候选、工具页的转换与编辑、训练的试听，以及项目导出的文件。

项目中每一句的版本（台词录音）**不**在这里列出，它们在项目页中管理（见[项目](/docs/guide-projects#版本)）；项目和章节**导出**的文件会列出。

## 查找

顶部有三个筛选条件，可以组合使用：

- **搜索文本**：按结果的文本或名称搜索；
- **模型**：**全部模型**，或某一个模型；
- **收藏**：只显示收藏的结果。

列表一次加载 50 条，滚到底部点 **加载更多**。

## 每条结果

每条显示文本（或名称）、时长、波形（点击跳转播放位置）、模型、耗时、实时率（RTF）和种子，以及警告和许可声明（例如 Fish Speech 的 “Built with Fish Audio”）。右侧菜单：

| 操作 | 作用 |
| --- | --- |
| **收藏** / **取消收藏** | 标记为收藏，配合顶部的 **收藏** 筛选 |
| **下载** | 下载文件 |
| **在文件夹中显示** | 在服务器上打开所在的文件夹（只在服务器本机的浏览器中出现） |
| **用作参考音频** | 打开合成页，把这条结果作为 **一段音频** 的参考，文本一并填入 |
| **保存为音色** | 输入 **新音色的名称**，存进音色库 |
| **用这些设置重新运行** | 打开合成页，载入生成它的模型、音色、文本和参数（设置过种子时种子也相同）；适用于合成产生的结果 |
| **删除** | 删除这条结果及其文件 |

列表中多于一条结果时，**全部下载** 把当前列出的结果打包下载。

## 文件在哪里

结果文件保存在数据文件夹的 `outputs/` 中（可在 **设置 › 存储 › 结果** 中更改），每条结果的来源（模型、参数、耗时、许可标记）记录在数据库中。

数据文件夹可以移动、改名或复制：用新位置启动 Mizuoto（`MIZUOTO_DATA_DIR`，或 `mizuoto webui --data-dir`），所有结果都会从那里播放。文件已不在的结果显示 **文件缺失**；`mizuoto output check` 会列出这些结果，加 `--prune-missing` 则删除它们。

## 命令行

```bash
mizuoto output list                       # 最近的结果
mizuoto output list -m qwen3tts/1.7b-base -s "你好" --limit 100
mizuoto output info <结果id>              # 结果及其生成方式
mizuoto output delete <结果id>
mizuoto output check                      # 文件缺失的结果和音频文件
```
