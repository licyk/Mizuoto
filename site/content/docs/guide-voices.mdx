**音色** 页是音色库。一个音色可以在 **合成**、**项目**、**工具** 中反复使用，换模型时 Mizuoto 会自动判断它在新模型上怎么用。

音色有四类：

| 类别 | 来源 |
| --- | --- |
| **来自音频** | 一段或几段参考音频及其文本，用来克隆 |
| **设计** | 设计模型按文字描述生成的声音；生成的那段音频成为它的主音频，因此也能被其他模型克隆 |
| **预置** | 某个模型的预置说话人，只能用于这个模型 |
| **训练** | 训练得到的音色，带有专属的微调权重（见[训练](/docs/guide-train)） |

每个音色是数据文件夹下 `voices/<名称>/` 中的一个文件夹（`voice.json` 和 `references/` 中的 FLAC 音频）。列表就是对这些文件夹的扫描，直接复制进去的音色文件夹也会出现。

## 音色列表

顶部有 **搜索音色**、按类别筛选的标签、**导入音色** 和 **新建音色**。每张卡片显示名称、类别、描述、语言、**N 段音频** 和总时长；有主音频的可以直接 **播放其音频**，**在合成中使用** 会带着这个音色跳到合成页。点卡片打开音色页。

## 新建音色

点 **新建音色**，在对话框中先填 **名称**，再选一种方式：

<Tabs items={["来自音频", "设计", "预置"]}>
<Tab value="来自音频">

1. 添加一段或几段参考音频：拖放或选择文件、**录音**（3 到 30 秒的清晰语音为佳）、**服务器文件** 或 **之前的结果**。
2. 每段音频下方有 **音频中说的内容**。可以留空：**缺少的文本会在安装语音识别后自动填写。**
3. 选择 **语言**（或 **任意语言**）。
4. 点 **创建**。

</Tab>
<Tab value="设计">

需要一个能设计音色的已安装模型，例如 Qwen3-TTS 1.7B VoiceDesign；没有时提示 **没有安装可设计音色的模型。**

1. 选择 **设计模型**。
2. 在 **描述音色** 中写下想要的声音，例如“温暖低沉的男声，平静，略带沙哑”。
3. **音色样例要说的话** 是试听用的句子，可以修改。
4. 点 **生成**。每次生成一个候选，出现在 **候选** 中（保留最近 4 个），逐个试听。
5. 在满意的候选旁点 **保留这个**，它就成为一个 **设计** 类音色。

</Tab>
<Tab value="预置">

1. 选择 **模型**（只列出带预置说话人的已安装模型）。
2. 选择 **说话人**。
3. 点 **创建**。

</Tab>
</Tabs>

还可以在合成结果的菜单中点 **保存为音色**，把任意一条结果存为音色。

## 音色页

音色页顶部显示名称和类别；设计出的音色还显示 **由 模型 设计** 和当时的描述，预置音色显示 **模型 的说话人 名称**。

### 参考音频

（预置音色没有这一部分。）每段音频一行：播放按钮、波形、时长与采样率，以及：

- **主音频** 标记，或 **设为主音频** 按钮。克隆时主音频排在最前；音色列表中播放的也是它。
- 删除按钮（至少保留一段）。
- 下面的文本框是这段音频的文本，改完点 **保存**（或按回车）。

**重新识别** 用语音识别重新转写所有音频；**添加音频** 再加一段。

### 微调权重

（来自音频和训练类的音色才有。）一个音色可以带有某个引擎的专属微调权重，目前是 GPT-SoVITS：一个 GPT 的 `.ckpt` 和一个 SoVITS 的 `.pth`。

1. 选择 **引擎**。
2. 按提示 **选择 gpt 文件（.ckpt）** 和 **选择 sovits 文件（.pth）**。
3. 点 **添加权重**，上传完成后显示 **已添加 GPT-SoVITS 的权重**。

权重的版本从文件中识别。同版本的 GPT-SoVITS 模型使用这个音色时会换上这套权重（在 **哪些模型可以使用** 中带有 **自有权重** 标记）；版本不同的模型给出提示并照常克隆。**音色仍保留其参考音频：引擎使用权重时也需要参考音频。** 训练实验导出的权重会自动加到音色上。

### 哪些模型可以使用

列出每个已安装的模型能否使用这个音色、以何种方式：**克隆**、**克隆（无文本）**、**预置说话人**、**设计** 或 **训练**，以及 **自有权重**、**先识别文本**、**裁剪以适配** 等标记；不能使用的写明原因。

克隆方式的行有 **准备** 按钮：提前为这个模型计算并缓存音色（参考音频的特征等），之后第一次合成会更快。不准备的话，第一次合成时也会自动做一次。

### 试听

选择一个可用的 **模型**，修改 **文本**，点 **合成**。结果列在下方。

### 详情

**名称**、**语言**、**标签**（逗号分隔）和 **描述**，改完点 **保存**。

### 页面底部

- **删除**：把音色移到数据文件夹的回收站（`trash/`）。
- **导出**：下载一个 zip，包含音色信息、参考音频和微调权重。
- **在合成中使用**：带着这个音色打开合成页。

## 导入

在音色列表点 **导入音色**，选择一个导出的 zip。

## 命令行

```bash
mizuoto voice add Me --ref me.wav                                     # 来自音频；缺少的文本自动识别
mizuoto voice design Narrator -m qwen3tts/1.7b-voice-design -d "温暖低沉的男声，语速平缓"
mizuoto voice from-preset qwen3tts/1.7b-custom-voice vivian           # 预置说话人
mizuoto voice fit narrator -m qwen3tts/1.7b-base                      # 这个模型能否、如何使用
mizuoto voice prepare narrator -m qwen3tts/1.7b-base                  # 提前准备
mizuoto voice add-weights me -e gptsovits -f gpt=me.ckpt -f sovits=me.pth
mizuoto voice export narrator -o narrator.zip
mizuoto voice import narrator.zip
```

其余命令（`add-ref`、`set-transcript`、`retranscribe`、`edit`、`remove`…）见 `mizuoto voice --help` 和[命令参考](/docs/cli-commands)。`voice add`、`voice from-output` 和 `voice edit` 接受 `--consent`：一条关于这是谁的声音的可选说明，随音色保存（`voice info` 会显示），但不是必需的。
