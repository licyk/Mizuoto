**设置** 在导航栏最下方，顶部的标签页分为九个部分。大部分设置改动后立即保存，并提示 **设置已保存**；文本框在离开输入框时保存；**存储** 部分需要点 **保存**。

设置保存在数据文件夹的 `settings.toml` 中。每一项也可以用环境变量覆盖，例如 `MIZUOTO_SERVER__PORT=8000`；被环境变量设置的项在界面中标有 **由环境变量设置**，Mizuoto 嵌入在其他应用中时还可能显示 **由运行 Mizuoto 的应用程序设置**。配置文件与环境变量的完整说明见[配置与环境变量](/docs/cli-config)。

## 常规

| 设置 | 说明 |
| --- | --- |
| **语言** | 界面语言；**自动** 跟随浏览器 |
| **服务器启动时打开浏览器** | `mizuoto webui` 启动后是否自动打开浏览器 |
| **服务器地址**、**端口** | 监听的地址（默认 `127.0.0.1`，只允许本机访问）和端口（默认 7869）。**下次启动服务器时生效。** |
| **访问令牌** | 显示 **已设置访问令牌** 或 **未设置访问令牌**。输入后点 **设置令牌**；**清除令牌** 取消。设置后，每个接口请求都需要带上令牌，浏览器会弹出对话框询问 |

让其他电脑访问时请设置访问令牌，见[远程访问与安全](/docs/advanced-remote)。

## 计算

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| **默认设备** | **自动** | 引擎设备为“自动”时使用的设备，可选本机找到的设备 |
| **空闲多少分钟后卸载模型（0：从不）** | 20 | 模型这么久没被使用就卸载 |
| **保留在内存中的模型数** | 3 | 所有引擎合计同时保持加载的模型数；超出时先卸载最久未用的空闲模型 |
| **同时运行的 GPU 任务数** | 1 | 同一块显卡上可以同时运行的 GPU 任务数 |
| **同时运行的合成任务** | 1 | 跨所有引擎和设备同时运行的合成任务数（合成、音色转换、语音编辑）；其余任务在队列中按顺序等待，显示 **等待其他合成任务**。合并为一批运行的请求（**合并等待中的请求**）算一个任务 |
| **编译模型（torch.compile）** | 关 | 加快 F5-TTS、CosyVoice、GPT-SoVITS v4/v5 和 IndexTTS 的合成；每种新长度的第一次合成会因编译而较慢。需要 C++ 编译器，没有时引擎照常运行（给出一次警告）。对之后加载的模型生效 |

下方列出本机的设备、每块显卡已用/总显存，以及正在使用的 torch 及其构建。缺少 torch 或其构建不适合本机时，会显示问题和安装正确构建的命令。每个引擎自己的设备和精度在 **模型 › 引擎** 中设置；当前已加载的模型见顶栏的 **内存中的模型**。

## 远程主机

引擎可以在其他机器上运行：在那台机器上运行 `mizuoto agent`（它有自己的引擎与模型），在这里添加它，再在 **模型 › 引擎** 中把它选为某个引擎的设备。训练始终在本机进行。

- 每台主机显示状态（**在线**、**离线**、**被拒绝**）、**设备**、**已安装的引擎** 和 **使用它的引擎**，可以修改或移除。**重新检查** 刷新所有主机的状态。
- **添加主机**：填写 **名称**（引擎的设备写作 `名称/cuda:0`）、**地址**（如 `192.168.1.20:7870`）、**令牌**（agent 生成令牌时会显示它），需要时打开 **TLS** 并指定 **本机上的 CA 文件**，然后点 **添加**。
- 移除主机后，在它上面运行的引擎回到本机运行。

详见[远程主机](/docs/advanced-remote)。

## 语音

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| **默认模型** | **无** | 合成页第一次打开时选中的模型，也是兼容 OpenAI 的接口在没有指定可用模型时使用的模型 |
| **结果格式** | WAV | WAV、FLAC、MP3、OGG、M4A |
| **结果采样率** | **模型原生** | 或 16–48 kHz |
| **音量均衡** | **峰值** | **峰值**、**响度** 或 **不处理** |
| **自动识别没有文本的参考音频** | 开 | 参考音频缺少文本时用语音识别补全（需要已安装语音识别） |
| **语音识别模型** | Whisper large-v3-turbo | 已安装语音识别模型时显示 |
| **参考音频对模型来说过长时** | **裁剪以适配** | **裁剪以适配**（在限制之前最安静的位置截断，原文本作废），或 **拒绝** |
| **拒绝模型不接受的参数** | 关 | **关闭：忽略这些参数并给出提示。** 打开后直接拒绝请求。超出范围的值始终会被拒绝 |
| **合并等待中的请求** | 开 | 见下文 |

**合并等待中的请求**：同一模型和音色、仅文本不同的请求，在支持批处理的引擎上（Qwen3-TTS、GPT-SoVITS、OmniVoice）合并为一批运行。具体来说，只有一段文本、没有指定种子的请求才会合并：正在运行的任务在调用引擎前，把排队中设置完全相同的任务一起带上，一次生成，再分别保存各自的结果；批处理失败时，这些任务回到队列中各自运行。指定种子的请求不合并，因为批处理时随机数的取法不同。[项目](/docs/guide-projects#生成)的生成正是借助这一点加速的。

## 下载

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| **下载来源** | **Hugging Face** | **Hugging Face**、**hf-mirror.com**、**ModelScope** 或 **自定义**（再填写 **自定义地址**，一个与 Hugging Face 兼容的服务器）。某个来源缺少的文件会从下一个有它的来源下载 |

| **同时下载的文件数** | 2 | 1–8 |

详见[下载来源](/docs/advanced-downloads)。

## 存储

**文件夹** 中可以把以下内容放到别处，每项下方显示当前的默认位置：**模型**、**音色**、**结果**、**缓存**。留空表示使用数据文件夹中的默认位置。

| 设置 | 说明 |
| --- | --- |
| **浏览器可以打开的文件夹** | 每行一个。**服务器文件**、**导入模型文件夹** 等对话框只能浏览这些文件夹。**留空：你的主文件夹、数据文件夹和所有驱动器。** |
| **多少天后删除结果（0：保留）** | 结果的保留天数（收藏的结果不删除）。当前版本只保存这个设置，尚不会自动删除旧结果 |

改完点 **保存**。移动文件夹时，Mizuoto 不会搬移已有的文件。

| 设置 | 选项 |
