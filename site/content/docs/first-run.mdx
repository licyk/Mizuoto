装好 Mizuoto 并运行 `mizuoto webui` 之后，本页带你完成第一次使用：从哪里开始，检查 torch 与引擎，了解模型下载做了什么，处理需要接受许可的引擎，最后完成第一次合成。每一步都给出网页界面和命令行两种做法。

## 从哪里开始

界面打开后直接进入 **合成** 页。不需要先做任何设置：演示引擎马上就能用（它用音调“说话”），可以在下载任何东西之前先熟悉界面。要用真正的引擎，需要关注三个地方：

| 位置 | 在这里做什么 |
| --- | --- |
| **设置 › 下载** | 选择 **下载来源**：**Hugging Face**、**hf-mirror.com** 或 **ModelScope**（在中国大陆，后两者通常更快），或 **自定义** |
| **设置 › 计算** | 本机的设备、每块显卡的显存，以及正在使用的 torch 及其构建，例如 `torch 2.8.0（cu128）`。缺少 torch 或其构建不适合本机时，会给出适合的构建和安装它的命令（`mizuoto doctor` 给出的结果相同） |
| **模型** | 模型目录中的每个模型，附带所属引擎、大小、所需显存和状态，以及 **下载** 按钮；见[下载模型](#下载模型) |

在 **合成** 页选择了尚未下载的模型时，**合成** 按钮会换成下载它的按钮。下载都是任务，可以随时离开页面。

<Callout type="info" title="需要接受许可的引擎">

接受许可之前，Fish Speech 和 IndexTTS 的模型无法下载。见下文[需要接受许可的引擎](#需要接受许可的引擎)。

</Callout>

## torch 与引擎

所有引擎都是 Mizuoto 的一部分，在服务器自己的进程中运行：不需要为每个引擎单独安装。一个引擎在装好 torch（演示引擎不需要）、且其实现存在时为 **可用**：内置的引擎都有实现，Fish Speech 和 IndexTTS 则需要各自的发行包（`mizuoto-fishspeech`、`mizuoto-indextts`）。否则 **模型 › 引擎** 中它的卡片显示 **不可用** 和所缺的内容，模型选择器中它的模型也标为 **不可用**。

解决办法是把缺少的部分安装到 Mizuoto 所用的 Python 中，然后重启 Mizuoto：

- torch：安装 `mizuoto doctor` 指出的构建，例如 `pip install "torch>=2.8" --index-url https://download.pytorch.org/whl/cu128`（各平台的命令见[安装](/docs/installation#安装方式)）。
- 需要接受许可的引擎：安装它的 wheel，例如 `pip install dist/mizuoto_indextts-*.whl`。

在 **合成** 页选择引擎不可用的模型时，底部按钮会换成安装所缺内容的命令。命令行：

```bash
mizuoto doctor               # torch 与硬件是否匹配、各引擎、缺少的可选扩展
mizuoto engine list          # 列出引擎，含“Available”（是否可用）一列
```

有些语言需要可选扩展（GPT-SoVITS 的日语和韩语、IndexTTS-2.5 的日语）；`mizuoto doctor` 会列出缺少的扩展及其安装命令，见[可选扩展](/docs/installation#可选扩展)。

### 语音识别

克隆音色时，模型通常需要参考音频的文本。下载语音识别模型后，缺少的文本会自动补全：

```bash
mizuoto model download asr/whisper-large-v3-turbo
```

在界面中，语音识别显示为 **模型 › 引擎** 中标有 **供 Mizuoto 自身使用** 的引擎，它的模型在 **模型 › 模型** 中。

## 下载模型

在 **模型 › 模型** 中，模型按引擎分组，每个模型一行，显示大小、所需显存和状态：**未下载**、**下载中**、**部分下载**、**已安装**、**已损坏**。点 **下载** 开始；下载中的行显示已下载量、速度和剩余时间。

- 文件先下载到 `.part` 文件，中断后可以续传；每个文件下载完都会核对大小和 SHA-256。
- 某个来源缺少文件或文件有误时，自动换下一个来源（先用设置中的来源，再依次尝试 Hugging Face、hf-mirror、ModelScope）。
- 同一引擎多个模型共用的文件（例如 GPT-SoVITS 的编码器）会随第一个需要它的模型一起下载，在 **共享文件** 标签页中可以看到。
- 也可以在 **合成** 页选择模型后，点底部的 **下载 模型名（大小）**。

命令行：

```bash
mizuoto model list
mizuoto model download qwen3tts/1.7b-custom-voice
```

## 需要接受许可的引擎

Fish Speech（Fish Audio Research License）和 IndexTTS（bilibili Model Use License）的许可证限制了用途。它们各是一个单独的发行包（`mizuoto-fishspeech`、`mizuoto-indextts`，见[安装](/docs/installation)），下载它们的模型和共享文件、合成，都需要先接受许可。

1. 打开 **模型 › 引擎**，在该引擎卡片上点 **接受许可**（或在 **合成** 页选择它的模型后，点底部的 **接受 引擎名 的许可**）。
2. 对话框显示许可证的完整文本和原文链接。阅读后勾选 **我已阅读并接受此许可**。
3. 点 **接受许可**。卡片上显示 **已接受许可**，它的模型就可以下载了。

命令行：

```bash
mizuoto engine licence indextts            # 打印许可证全文
mizuoto engine accept-licence indextts     # 接受
mizuoto model download indextts/v2
```

接受的是许可证的某个具体版本；许可证更新后需要重新接受。另外：

- IndexTTS 的结果下方会显示其许可的提示：IndexTTS 的免责声明禁止未经声音主人许可克隆其声音。
- Fish Speech 的结果下方会显示 “Built with Fish Audio”；它的结果不能用作其他引擎的训练数据。
- F5-TTS 不需要接受许可，但其预训练权重（CC-BY-NC-4.0）仅限非商业用途，结果会带上对应的许可标记。

## 第一次合成

模型下载完成后，打开 **合成**，选择这个模型、一个音色，输入文本，点 **合成**。各选项的含义见[合成](/docs/guide-speak)。

第一次合成会把模型加载到服务器进程中，耗时较长；之后模型留在内存中，直到空闲超过设定的时间（**设置 › 计算**）。如果显卡的剩余显存少于模型所需，Mizuoto 会立即报错 **GPU 不可用或显存不足**，并在 **解决办法** 中说明如何处理，例如换一个设备或释放显存。
