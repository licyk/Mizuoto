**Settings** is at the bottom of the navigation; the tabs at the top split it into nine parts. Most settings are saved as soon as you change them, with **Settings saved**; text fields save when you leave them; **Storage** has its own **Save** button.

Settings are kept in `settings.toml` in the data folder. Each can also come from an environment variable, such as `MIZUOTO_SERVER__PORT=8000`; a value set that way is marked **Set by an environment variable**, and when Mizuoto runs inside another application it may show **Set by the application Mizuoto runs in**. The settings file and the environment variables are described in full in [Configuration and environment variables](/docs/cli-config).

## General

| Setting | What it does |
| --- | --- |
| **Language** | The UI's language; **Auto** follows the browser |
| **Open the browser when the server starts** | Whether `mizuoto webui` opens a browser |
| **Server address**, **Port** | The address to listen on (`127.0.0.1` by default: this machine only) and the port (7869 by default). **Takes effect the next time the server starts.** |
| **Access token** | Shows **An access token is set** or **No access token**. Type one and click **Set token**; **Clear token** removes it. With a token set, every API request must carry it, and the browser asks for it |

Set an access token before letting other machines connect; see [Remote access and security](/docs/advanced-remote).

## Compute

| Setting | Default | What it does |
| --- | --- | --- |
| **Default device** | **Automatic** | The device used by engines whose device is automatic; any device found on this machine |
| **Unload models after idle minutes (0: never)** | 20 | A model unused this long is unloaded |
| **Models kept in memory** | 3 | Models kept loaded at once, across all engines; beyond it the least recently used idle one is unloaded first |
| **GPU jobs at once** | 1 | GPU jobs that may run at once on one device |
| **Synthesis jobs at once** | 1 | Synthesis jobs (speak, voice conversion, speech editing) that run at once, across every engine and device; more wait in the queue in order, showing **Waiting for other synthesis jobs**. Requests run together as one batch (**Run waiting requests together**) count as one job |
| **Compile models (torch.compile)** | off | Faster synthesis on F5-TTS, CosyVoice, GPT-SoVITS v4/v5 and IndexTTS; the first synthesis of each new length is slower while it compiles. Needs a C++ compiler, else the engines run as before (with one warning). Applies to models loaded afterwards |

Below them are this machine's devices, with each GPU's used and total memory, and the torch in use with its build. When torch is missing or its build does not suit this machine, the problem is shown with the command that installs the right build. Each engine's own device and precision are set under **Models › Engines**; the models loaded now are in the top bar's **Models in memory**.

## Remote hosts

Engines can run on other machines: run `mizuoto agent` there (it has its own engines and models), add it here, then choose it as an engine's device under **Models › Engines**. Training stays on this machine.

- Each host shows its state (**Online**, **Offline**, **Refused**), **Devices**, **Installed engines** and **Used by**, and can be changed or removed. **Check again** refreshes every host.
- **Add a host**: a **Name** (engines name it in their device: `name/cuda:0`), the **Address** (such as `192.168.1.20:7870`), the **Token** (the agent prints it when it makes one), **TLS** and a **CA file on this machine** when needed; then **Add**.
- When a host is removed, the engines that ran there run on this machine again.

More in [Remote hosts](/docs/advanced-remote).

## Speech

| Setting | Default | What it does |
| --- | --- | --- |
| **Default model** | **None** | The model Speak chooses the first time, and the one the OpenAI-compatible endpoint uses when the request names no model it knows |
| **Result format** | WAV | WAV, FLAC, MP3, OGG, M4A |
| **Result sample rate** | **The model’s own** | Or 16–48 kHz |
| **Levelling** | **Peak** | **Peak**, **Loudness** or **None** |
| **Transcribe reference clips without a transcript** | on | Fill a missing transcript with speech recognition (when installed) |
| **Speech recognition model** | Whisper large-v3-turbo | Shown when a speech recognition model is installed |
| **A reference clip too long for a model** | **Refuse it** | **Refuse it**, or **Cut it to fit** (at the quietest point before the limit; its transcript is dropped) |
| **Refuse parameters a model does not take** | on | **Off: drop them with a warning.** A value out of range is always refused |
| **Run waiting requests together** | on | See below |

**Run waiting requests together**: requests for the same model and voice that differ only in their text run as one batch, on engines that take one (Qwen3-TTS, GPT-SoVITS, OmniVoice). Only one-segment requests without a seed qualify: just before calling the engine, the running job takes the queued jobs with exactly the same settings along, makes them in one go and stores each one's result; if the batch fails, those jobs go back to the queue to run on their own. Requests with a seed are never joined, since a batch draws random numbers differently. Rendering a [project](/docs/guide-projects#rendering) relies on this to go faster.

## Downloads

| Setting | Default | What it does |
| --- | --- | --- |
| **Download source** | **Hugging Face** | **Hugging Face**, **hf-mirror.com**, **ModelScope** or **Custom** (then the **Custom endpoint**, a Hugging Face compatible server). A file one source lacks comes from the next that has it |
| **Repository** | **Each model's own repository** | Or **mizuoto-model mirror first**: **mizuoto-model mirrors the files Mizuoto downloads; what it lacks comes from each model's own repository.** The mirror is fetched from the chosen download source too |
| **Verify checksums** | on | Check each downloaded file's SHA-256 |
| **Files at once** | 2 | 1–8 |

More in [Download sources](/docs/advanced-downloads).

## Storage

Under **Folders**, these can be moved elsewhere, each showing its default location: **Models**, **Voices**, **Results**, **Cache**. Empty means the default place in the data folder.

| Setting | What it does |
| --- | --- |
| **Folders the browser may open** | One per line. Dialogs such as **Server files** and **Import a model folder** browse only these. **Empty: your home folder, the data folder and every drive.** |
| **Delete results after days (0: keep)** | How long results are kept (favourites are kept). This version only stores the setting; it does not delete old results yet |

Click **Save** after changing them. Mizuoto does not move existing files when a folder changes.
