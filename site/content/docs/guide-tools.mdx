**工具** 页有两个标签页：**音色转换** 和 **语音编辑**。两者都以一段已有的录音为输入，结果和合成结果一样出现在页面下方的 **结果** 中（也出现在[历史](/docs/guide-history)中），菜单操作相同。

## 音色转换

**用另一个音色说出录音里的话，保留原话和节奏。** 需要支持音色转换的模型：CosyVoice（300M、300M SFT、2、3）。

1. 在 **模型** 中选择一个 CosyVoice 模型。选择器只列出支持音色转换的模型；还没准备好时，底部按钮会先提供它还缺的步骤，例如下载（见[合成](/docs/guide-speak#模型还没准备好时)）。
2. 在 **录音** 中添加要转换的音频：拖放、选择文件、**录音**、**服务器文件** 或 **之前的结果**。
3. 在 **目标音色** 中选择：
   - **音色库**：音色库中的一个音色，使用它的参考音频作为目标声音；
   - **一段音频**：直接提供一段目标声音的音频。
4. 点底部的 **转换**。

命令行：

```bash
mizuoto convert speech.wav -m cosyvoice/cosyvoice2-0.5b --voice narrator -o converted.wav
mizuoto convert speech.wav -m cosyvoice/cosyvoice2-0.5b --ref target.wav -o converted.wav
```

## 语音编辑

**用同一音色把录音中的部分内容替换成新的词句。** 需要支持语音编辑的模型：F5-TTS（v1 Base、Base、E2-TTS）。

1. 在 **模型** 中选择一个 F5-TTS 模型。
2. 在 **录音** 中添加要编辑的音频。
3. 在 **修改** 中填写 **编辑后的完整文本**：整段录音在修改之后应该说的全部内容。最方便的做法是先点 **识别文本** 转写录音，再改动要替换的词句。模型读的是这段文本。
4. 标出每一处要替换的部分：
   - **起点（秒）** 和 **终点（秒）**：被替换的语音在录音中的位置；
   - **新的词句**：这一处的新内容（作为记录；模型依据的是上面的完整文本）；
   - **时长（秒）**：新语音的长度，留空（**自动**）则与原来的片段等长。

   **添加一处修改** 增加一行，行尾的按钮删除一行。只有填了起点和终点、且终点大于起点的行才会提交。
5. 点底部的 **编辑**。

缺少内容时底部会提示：**请添加录音**、**请填写编辑后的文本**、**请标出要替换的部分：起点和终点，单位为秒**。

命令行（`--span` 可重复，格式为 `起点:终点[:时长]`，单位为秒）：

```bash
mizuoto edit speech.wav -m f5tts/v1-base -t "编辑后的完整文本。" --span 1.2:1.8 -o edited.wav
mizuoto edit speech.wav -m f5tts/v1-base -t "编辑后的完整文本。" --span 1.2:1.8:0.9 --span 4.0:4.5
```
