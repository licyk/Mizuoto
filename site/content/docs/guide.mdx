本节逐个页面讲解 Mizuoto 的网页界面。还没有安装或启动 Mizuoto 的话，先看[快速开始](/docs/quick-start)。界面中的每个操作都有对应的 `mizuoto` 命令，见[命令行](/docs/cli)。

## 导航

左侧是导航栏（窗口较窄时移到底部）：

| 页面 | 用来做什么 |
| --- | --- |
| **合成** | 选模型和音色，把文本合成为语音 |
| **项目** | 由一组角色逐句朗读一本书、一份剧本或一段对话 |
| **工具** | **音色转换** 与 **语音编辑** |
| **音色** | 音色库：新建、设计、导入导出音色，查看各模型能否使用 |
| **训练** | 数据集与实验：用自己的录音微调模型 |
| **模型** | 模型下载、引擎、共享文件 |
| **历史** | 所有合成结果 |
| **设置**（最下方） | 语言、服务器、计算设备、下载来源、存储、外观等 |

打开界面时回到你上次所在的页面。每个页面在切换后都保持原来的状态（包括滚动位置）；音色、数据集、实验和项目的详情页各自独立保持。

## 顶栏

右上角有四个按钮：

- **任务**：有任务在运行时显示转圈的图标和数量（**N 个运行中**）。点开是任务面板，列出最近的 30 个任务；每个任务卡片显示状态、进度（下载还显示已下载量、速度和剩余时间），并可以 **取消**、**重试** 和查看 **日志**。点 **全部任务** 打开完整的任务列表，可按 **全部**、**进行中**、**已结束** 筛选，**清除已结束** 清理历史。排队中的任务会说明在等什么，例如 **等待 GPU**、**等待引擎**、**等待其他合成任务**（见[设置](/docs/guide-settings#计算)中的 **同时运行的合成任务**）、**等待其他下载**；另一个任务占用着 GPU 时可以点 **仍然运行**，在显存足够时并行运行。
- **内存中的模型**：显示已加载的模型数（**已加载 N 个**）。点开列出每个已加载的模型及其设备、权重占用的内存，以及它是 **忙碌** 还是 **空闲**；可以 **卸载** 单个模型，或点 **释放显存** 一次卸载所有空闲的模型。上一个请求失败的引擎也会列出，并附上错误。
- **帮助**：在浏览器的新标签页中打开本文档。
- **主题**：在浅色、深色和跟随系统之间切换。更多外观选项在 **设置 › 外观**。

在其他页面启动的任务完成或失败时，屏幕底部会弹出提示；失败的提示带有 **查看日志** 按钮。

## 页面底部

**合成**、**工具** 等页面的主要按钮固定在页面底部，旁边是本页启动的任务卡片和错误说明。错误说明包括 **原因**、**解决办法**，以及可展开的 **详情**，可以一键 **复制**。

模型还没准备好时，底部的主按钮会换成它缺少的那一步：**启用**、**接受 引擎名 的许可**、安装引擎所缺内容（torch，或需要接受许可的引擎的发行包）的命令，或 **下载 模型名（大小）**，并在执行时显示进度。
