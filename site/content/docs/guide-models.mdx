**模型** 页有三个标签页：**模型**（各引擎的模型目录）、**引擎**（各引擎的可用状态与设置）和 **共享文件**（同一引擎多个模型共用的文件）。

## 模型

模型按引擎分组：语音合成引擎在前，语音识别等辅助引擎其次，演示引擎在最后。引擎不可用时，该组会说明缺什么：**引擎名 需要 torch 才能使用这些模型（mizuoto doctor）。**

每个模型一行，显示名称、变体、大小、所需显存（**显存 N GB**）和说明，以及状态：

| 状态 | 含义 |
| --- | --- |
| **未下载** | 还没有下载 |
| **下载中** | 正在下载，显示已下载量、速度和剩余时间 |
| **部分下载** | 有文件夹但没有下载完，或它需要的共享文件还缺 |
| **已安装** | 下载完成，所有文件都核对过 |
| **已损坏** | 某个文件的大小不对，或校验失败 |
| **内置** | 演示引擎的模型，不需要下载 |

可以做的操作：

- **下载**：下载缺少的文件。下载会续传、核对每个文件的大小和 SHA-256，某个来源缺文件时自动换下一个来源（见[下载来源](/docs/advanced-downloads)）。它需要的共享文件随之一起下载。
- **校验**：重新计算已安装模型所有文件的 SHA-256。完好时提示 **全部 N 个文件完好**，否则列出 **已损坏：文件名**。已损坏的模型可以删除后重新下载。
- 删除按钮：删除模型文件（确认提示 **删除 模型名？之后可以重新下载。**）。

### 导入模型文件夹

已经有模型文件（之前下载的、别处拷来的、微调的结果）时，点 **导入模型文件夹**，选择服务器上的一个文件夹。这个按钮只在服务器本机的浏览器中出现。

Mizuoto 根据文件判断它属于哪个引擎、哪个变体：

- 文件大小与目录中的某个模型一致时，再核对 SHA-256，通过后作为该目录模型导入；
- 否则作为用户模型导入，id 为 `引擎/文件夹名`。

命令行可以指定名称，或移动而不是复制：`mizuoto model import <文件夹> [--name 名称] [--move]`。

## 引擎

每个引擎一张卡片：

- 标题下方是模型数量和许可名称（语音识别显示 **供 Mizuoto 自身使用**），右侧是 **可用** 或 **不可用**；引擎在远程主机上运行时还显示 **在 主机 上**。
- 一句引擎说明。不可用时说明缺什么：**需要** *torch*（或 *mizuoto-indextts* 等）**，但尚未安装：运行 mizuoto doctor 查看安装方法。** 除了需要接受许可的引擎是单独的发行包，其他引擎都是 Mizuoto 的一部分（见[首次运行](/docs/first-run#torch-与引擎)）。

### 设备、精度、启用

- **设备**：**自动**，本机上该引擎支持的设备（如 `cuda:0`、`cpu`），以及已添加的、该引擎在其上可用的远程主机的设备（显示为“主机 · 设备”）。选了远程设备后，这个引擎在那台机器上运行，卡片显示 **在 主机 上**，其依赖也由那台机器管理（见[远程主机](/docs/advanced-remote)）。
- **精度**：**自动**、`bf16`、`fp16`、`fp32`。
- **已启用**：关闭后这个引擎的模型不能使用，合成页底部会改为提供 **启用** 按钮。

修改这些设置会卸载该引擎的模型，下次使用时按新设置加载。

### 选项

引擎有加载选项时，卡片上有 **选项**：

| 引擎 | 选项 |
| --- | --- |
| CosyVoice | `fp16`：在 GPU 上用半精度，更快，结果略有不同 |
| IndexTTS 2 / 2.5 | `use_qwen_emo`（把文字描述的情感转成权重的情感模型，约 1.2 GB）、`use_torch_compile` |
| F5-TTS | `ode_method`（`euler` 或 `midpoint`） |
| Qwen3-TTS | `fused_projections`：快速模式，在 GPU 上快几个百分点，结果不再逐位一致 |

**更改在模型下次加载时生效（其模型现在会被卸载）。** **设置 › 计算** 中的 **编译模型（torch.compile）** 可以同时为多个引擎提速。详见[性能](/docs/advanced-performance)。

### 检查本机

展开 **检查本机**，列出这个引擎在本机上的检查结果：torch 及其构建是否与显卡匹配、引擎是否可用、它能用到的可选扩展（如 GPT-SoVITS 的日语前端），有问题的项后面附带修复命令。命令行：`mizuoto doctor <引擎>`。

### 许可

需要接受许可的引擎（Fish Speech、IndexTTS）卡片上有 **接受许可** 按钮，打开许可全文；接受后显示 **已接受许可**。见[首次运行](/docs/first-run#需要接受许可的引擎)。

## 共享文件

**同一引擎的多个模型共用的文件，随第一个需要它们的模型一起下载一次。** 例如 GPT-SoVITS 的编码器、G2PW、NLTK 数据、Open JTalk 词典和训练用的判别器，IndexTTS-2 的 w2v-BERT、语义编解码器、CAM++、BigVGAN，以及 CosyVoice 的文本规范化语法。

每行显示名称、大小、说明和 **用于 模型列表**。可以单独 **下载** 或删除。缺少某个共享文件的模型显示为 **部分下载**。共享文件保存在数据文件夹的 `models/_assets/<引擎>/` 中。

## 命令行

```bash
mizuoto model list
mizuoto model download qwen3tts/1.7b-base qwen3tts/1.7b-voice-design
mizuoto model verify qwen3tts/1.7b-base
mizuoto model delete qwen3tts/1.7b-base
mizuoto model import /path/to/folder --name my-model
mizuoto engine list
mizuoto engine info qwen3tts
mizuoto doctor qwen3tts
mizuoto runtime                      # 当前已加载的模型
mizuoto asset list
mizuoto asset download gptsovits/s2d-v2pro
mizuoto config set engines.cosyvoice.device cuda:1
```
